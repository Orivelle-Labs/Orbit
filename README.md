## ✨ 把模型能力带到桌面

### 连接常用工具

为 Codex 和 Claude Desktop 配置 Orivelle 接入，选择节点、API Key 与兼容模型。按工具独立保存切换快照，支持恢复原有配置；模型目录随平台更新。

### 从想法到图片

在图片工作台描述画面、拖入参考图，生成新图片或继续编辑已有作品。按模型能力调整尺寸、质量、背景与格式，在本地历史中预览、保存、复制和再次编辑。

### 掌握账户与消费

集中管理 API Key，查看余额、预算、调用记录和用量趋势。菜单栏或系统托盘快捷面板让账户信息、桌面接入和图片任务随时可见。

## 🚀 获取并开始使用

从 [Releases](https://github.com/Orivelle-Labs/Orbit/releases/latest) 下载适合设备的安装包：macOS 15 及以上的 Apple 芯片 Mac 使用 `.dmg`，Windows x64 使用 `-setup.exe`。

1. 打开 Orbit，选择「连接账户」，在系统浏览器中登录 Orivelle 并授权。
2. 在「API Key」选择或创建默认密钥，到「接入」选择节点并连接桌面工具。
3. 打开「图片工作台」开始创作，或在「用量」查看全平台调用与实际消费。

具体操作、客户端兼容与常见问题见[使用指南](docs/user-guide/usage.md)。

### 随时打开，保持顺手

关闭窗口默认收起至菜单栏或系统托盘，后台图片任务与 Claude 本地转发继续运行。主题可跟随系统，也可在设置中调整语言、窗口行为和本地图片空间；正式版本支持在应用内检查、下载并确认安装更新。

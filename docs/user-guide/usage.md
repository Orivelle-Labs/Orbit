# Orbit 使用指南

Orbit 将账户、桌面工具接入、图片创作和平台用量集中在桌面。安装包与产品预览见[项目首页](../../README.md)。

## 安装与连接账户

- macOS：Apple 芯片，macOS 15 或更高版本；打开 `.dmg`，将 Orbit 拖入「应用程序」。首次打开若提示无法验证开发者，确认来自项目 Releases 后，在系统设置的隐私与安全性中选择「仍要打开」。
- Windows：x64；运行 `-setup.exe` 并按提示安装。

打开 Orbit，选择「连接账户」，在系统浏览器中登录 Orivelle 并授权。首页可查看余额或可用预算，顶部「刷新数据」更新账户、节点、模型和本地状态。

## API Key 与桌面工具

### 管理和选择密钥

「API Key」支持搜索、筛选、查看详情、创建、编辑、轮换、重置消费计数、撤销和删除。金额、滚动窗口和速度策略遵循平台规则；只读账户可查看，管理和领取接入凭据需相应可写权限。

默认密钥保存在当前设备，由原生层交付至系统凭据存储。主动查看明文时，30 秒后或窗口失焦即隐藏；复制通过原生剪贴板完成。管理操作因断网而结果未知时，先选择「核对结果」，避免重复创建或轮换。

「接入」使用 API Key 页选定的默认密钥。改变默认选择后，可对已有工具选择「更新接入」并重启客户端；已有绑定在确认更新前继续使用原密钥。旧版升级后若要求重新授权，重新连接账户、选择正常密钥并完成接入；明确关联的旧 Orbit 自动密钥由平台清理，手动创建的密钥保留。

### 接入与切回

自动配置支持 macOS Apple 芯片和 Windows x64 的默认配置位置。Windows 支持官方 MSIX，以及具备相同配置能力的官方 EXE 安装。Orbit 按应用身份、配置能力和本地文件结构判断兼容性；客户端更新或组织托管策略变化时，以重新检查的结果为准。

1. 在「API Key」设好默认密钥，到「接入」选择节点。
2. Codex 使用当前账户与节点下支持 Responses 的兼容文本模型；Claude Desktop 的 Sonnet、Opus、Haiku 分别选择支持 Messages 的实际模型。不同渠道按当前授权目录展示，无需分别选择 Key。
3. 选择「接入 Orbit」，核对节点和密钥并确认，再完整退出并重新打开对应客户端。Claude 已接入后仍展示三个实际模型绑定。
4. 需要切回时选择「取消接入」，确认后重启客户端。每个工具保留独立快照。

保存时客户端仍运行，状态显示「待重启」；未运行则显示「待启动」。确认旧实例退出、新实例在保存后启动且配置有效后显示「已连接」。此状态说明本地配置与启动条件满足，实际模型调用结果仍由客户端反馈。

Orbit 在启动时及每五分钟同步当前账户和节点的模型目录，隐藏窗口后仍继续。Codex 保留仍可用的默认模型；失效时选择目录首个兼容项。目录已更新但客户端未显示时，重启客户端。

### 配置恢复与常见问题

接入前的配置完整加密备份。取消接入时，未修改的文件按原字节恢复；兼容的 MCP、其他配置条目及个人偏好改动会尽量保留。其他工具已改变活动路由、专用目录或 Orbit 条目时，先处理冲突，再重新预览恢复。Codex 的 `auth.json` 继续由原客户端或切换器管理。

- **没有可选模型或节点**：确认账户已连接，选择可用节点并刷新；仍缺模型时请管理员核对权限。
- **无法预览或应用**：检查安装状态和提示的配置能力；组织策略限制需由设备管理员处理。
- **Claude 要求迁移旧配置**：先在 Claude 完成迁移，退出后重新预览。
- **Claude 连接后无法调用**：其请求通过 Orbit 本机转发，使用时保持 Orbit 运行。

节点旁的延时来自本机访问健康端点的 HTTP 往返，不调用模型；实际生成速度还受上游和负载影响。接入页前台每 30 秒更新，也可手动刷新。

## 图片创作与本地历史

### 生成、编辑与价格

连接账户后可先准备提示词、参考图和草稿，提交前选择可用节点、API Key 与模型。同一账户下切页或切换节点、密钥保留草稿；退出或切换账户时清空。

1. 描述想要的画面或修改要求；编辑时拖入 PNG、JPEG 或 WebP 参考图。
2. 按需展开「高级选项」，调整当前模型支持的参数。背景默认为不透明，可选择透明；收起后已选设置继续生效。
3. 核对按钮上方的服务档位与计费信息，再选择「生成图片」或「编辑图片」。

标准请求每次一张，支持最多五张参考图。高级图像 API 可提供多张输出、最多十六张参考图、自定义尺寸、质量、格式、压缩、画面规划、审核、流式预览、保真度及 PNG 蒙版等控制；选项随模型变化。SVG 可设置编写模型与推理强度，GIF 可设置帧数与帧间隔。

默认一张、自动质量与尺寸、PNG 以及不透明或透明背景使用标准价；指定质量、尺寸、其他格式、多张输出或超过五张参考图等高级控制使用高级价。已调整参数显示在高级选项标题旁，透明背景可能增加实际图片 Token。

「查看价格」展示账户适用的标准与高级两档价格，每档独立按张或 Token 计费。按张显示预计金额，Token 费用在完成后按实际用量确认；单价单位为每 1M Token。未配置当前档位价格时不能提交，明确零价可正常使用。实际消费以平台记录为准。

Orivelle 会处理提交的提示词与参考图，收到的图片保存在本机。

### 保存、再次编辑与结果核对

在「本地历史」预览、复制、另存或再次编辑图片。标题默认使用 Request ID，可改成本地名称；详情保留原始请求 ID、模型名称、格式、分辨率、文件大小和生成时间。预览按原比例显示。

SVG 以渲染后的图片预览和复制，另存保留原文件；GIF 使用动图预览，「复制首帧」复制静态图，另存保留完整动画。SVG/GIF 需转换为 PNG、JPEG 或 WebP 才能作为编辑参考图。

本地保存失败时，检查空间并选择「重试本地保存」，只保存已收到的结果。已提交请求在取消等待或断网后仍可能完成并计费；「结果待确认」时先刷新核对，避免直接重复生成。

## 用量、设置与更新

「用量」展示当前账户通过全部平台入口产生的调用与消费，可选今天、近 7 天、近 30 天或自定义时段，一次最多 90 个自然日。请求数、Token、已确认消费与待确认笔数分开呈现，不同币种分别展示；调用记录支持筛选、分页与详情。汇总可能稍晚，未知费用保留原状态。只读账户也可查看本人用量。

设置可调整主题、语言、图片磁盘和预览缓存上限。空间达到上限时，先另存需保留的图片，再清理历史。

关闭窗口默认收起至菜单栏或系统托盘，后台图片任务和 Claude 转发继续。点击图标打开快捷面板，查看余额或预算、今日消费、接入与图片任务；点击外部或按 Escape 收起。可在设置中改为关闭时退出；真正退出会停止 Claude 转发，进行中任务按界面提示处理。macOS 支持 `⌘,` 打开设置和 `⌘Q` 退出。

正式版本默认启动时检查更新，也可在设置中手动检查。下载完成后确认「安装并重启」，网络中断可重新下载。没有应用内更新通道的旧版本，可从项目 Releases 手动安装新版。

遇到问题时记录 Orbit 版本、操作系统与界面提示；需要诊断报告时，在设置中先预览再保存。
